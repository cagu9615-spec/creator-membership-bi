# CreatorHub Multi-Platform BI Pipeline

An end-to-end data integration warehouse and BI reporting pipeline connecting **Stripe**, **Shopify**, **Substack**, **Calendly**, and **Ebook Sales** datasets.

## Repository Structure
- `docs/`: Strategic documentation, data dictionaries, and KPI definitions.
- `sample_data/`: Seed datasets for offline CSV processing.
- `sql/`: Data warehouse transformation scripts (Raw, Staging, Dimensions, Facts, Marts).
- `apps_script/`: Automated API extractors for platform integration.
